# 使用与配置

面向使用者的详细说明：提醒什么时候出现、队列怎么走、点开之后会发生什么，以及设置项和本地存储的位置。功能概览和安装见 [README](../README.md)，实现细节见 [开发文档](./DEVELOPMENT.md)。

## 什么时候会提醒

### 任务完成

任意 DSH 会话从“运行中”变为“空闲”，并且满足下面条件时，右下角出现大肥鱼：

- 不是空白会话；
- 没有等待回答 / 等待确认的请求；
- 不是用户手动停止生成（点击“停止生成”，或连按两次 Esc）。

### 等待回答 / 等待确认

出现新的问答或审批请求时，和任务完成走同一条提醒队列：

- 不是弹出后自动消失的 toast，而是一直留在队列里等你处理；
- 队首标题显示“等你回答”或“等你确认”，气泡里显示“还有 N 个”；
- 问答和审批按发生顺序排队，不会被后来的任务完成插队；
- 插件首次加载前就已存在的待交互请求不会补提醒，只响应之后新出现的请求。

## 队列规则

- 多个会话先后产生提醒时排成 **FIFO 队列**，大肥鱼只出现一个。
- 同一会话重复触发只更新队列里的条目，不会重复占位。
- 点一次只处理一个会话；队列还有条目时，处理完会回到待机等待下一次点击。

以三条提醒为例：

```text
会话 A 完成   ─┐
会话 B 等你回答 ─┼─▶ 队列 [A完成, B回答, C确认] ──点击──▶ 打开 A，队列 [B, C]
会话 C 等你确认 ─┘                                ──点击──▶ 打开 B，队列 [C]
                                                  ──点击──▶ 打开 C，队列 []
```

## 点开提醒

### 点击大肥鱼

点击大肥鱼（或聚焦后按 Enter / 空格）：

1. 立即打开 **队首** 会话，气泡上正在报的就是这条。
2. 播放一段随机“点击回应”动画，动画播完这条才从队列中弹出。
3. 队列还有会话时，弹出后回到待机进入下一轮等待；队列清空时，动画播完最后一帧就直接收起。

动画播放期间的新点击会直接忽略，避免一次点掉多条。

### 直接在会话列表里点开会话

不点大肥鱼，而是从会话列表打开被提醒的会话，同样会结算这条提醒：

- 点开的会话在队列里但还没轮到它上屏：这条移到队首并播放点击回应动画，动画播完后从队列中移除，其余提醒顺序不变。
- 点之前你本来就停在这个会话里：移到队首后立即从队列中移除，直接进入下一轮等待，不再重复播动画。
- 气泡上已经在报的那条（队首）不会因为你点开它的会话而重复结算。
- 点会话行里的“更多”“新会话”等按钮不算打开会话，不影响队列。

### 清空提醒

气泡右上角的 `×` 可以随时清空整个队列并收起大肥鱼。

## 点击回应动画

点击回应动画共 9 段，随机选择，并避免与上一次连续重复：

| id | 名称 | 动作 |
| --- | --- | --- |
| `wave` | 元气挥手 | 举手欢呼挥手 |
| `happy` | 开心跃动 | 开心跳起、冒出爱心 |
| `shy` | 害羞惊讶 | 捂脸害羞 |
| `tickle` | 挠痒咯咯笑 | 被挠痒咯咯笑 |
| `angry` | 傲娇生气 | 生气鼓起脸转过身 |
| `scared` | 被吓一跳 | 猛地一激灵 |
| `meet` | 头顶开光 | 跳起来抓碎头顶的东西、爆闪星光 |
| `wake` | 惊醒 | 打瞌睡被惊醒 |
| `tumble` | 原地左转奔跑 | 左转一圈跑起来、摔一跤 |

## 提示音

- 任务完成使用内嵌的钉钉提示音；等待回答 / 等待确认使用另一段三音提示，便于区分。
- 浏览器自动播放策略要求页面先获得一次用户手势（点击或按键），之后才能稳定发声。
- MP3 被策略拦截时会自动退回 WebAudio 合成音，视觉提示不受影响。
- 大肥鱼已经显示时，新的提醒只入队，不重复响铃。

## 子智能体

子智能体（`subagent`、子智能体 fork 出来的会话、AgentTeams 成员）完成任务时**默认不提醒**，避免一个主任务在后台跑出大量提醒：

- 判定依据是宿主会话列表的元数据：`origin` 为 `subagent`，或带有所属主会话 `parentId` 的会话都算子智能体会话。
- 只跳过“任务完成”这一类；子智能体会话发起的 **等待回答 / 等待确认** 仍然照常提醒，否则请求可能一直无人处理。
- 需要看到子智能体完成提醒时，在设置里打开“子智能体完成”开关即可。

## 外观与操作

- **拖动**：大肥鱼可以拖到任意位置，松手后保存。
- **缩放**：鼠标悬停时显示右下角缩放手柄，拖动调整大小。基准为动画原始规格 216×228，可调 0.5～2 倍，首次出现默认 0.5 倍。
- **记忆**：位置和大小保存在 `localStorage`，刷新页面后恢复；窗口尺寸变化时会自动收回视口内。
- **触屏**：触屏设备没有悬停，缩放手柄常显。
- **主题**：颜色使用宿主的 `--dsw-alias-*` 主题令牌，深浅色主题都能融入。
- **语言**：文案跟随宿主语言，提供 `zh` / `en` 两套字典。
- **键盘与读屏**：大肥鱼是有 `role="button"` 的焦点元素，支持 Enter / 空格；读屏软件合成的 click 也能触发切换。

## 设置项

在 **设置 → 通用 → 任务完成提醒** 中可以调整：

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| 提醒 | 开启 | 总开关；关闭后不再产生新的大肥鱼提醒 |
| 声音 | 开启 | 控制完成提示音与等待提示音；打开时会试听一次 |
| 子智能体完成 | 关闭 | 打开后，子智能体会话完成时也显示大肥鱼；等待回答/确认始终提醒 |

## 本地存储

设置保存在 `localStorage`：

| 键 | 内容 |
| --- | --- |
| `dsh.taskNotify.settings.v1` | `{"enabled": true, "sound": true, "notifySubagent": false}` |
| `dsh.taskNotify.spritePos.v1` | `{"left": number, "top": number}`，单位：像素 |
| `dsh.taskNotify.spriteScale.v1` | 缩放比例，`0.5`～`2`，默认 `0.5`，1 为动画规格大小（216×228） |

需要重置时，在浏览器控制台删除对应键并刷新页面即可。

提醒队列只保存在内存中，刷新页面会清空，避免恢复出已经过期的提醒；设置、位置和大小会保留。
